# BlaBlaRide (blablaride.de)

Category: mobility-travel

## Concept
A concept landing page for a friendly carpooling idea: how sharing rides works, a browser-only cost-split calculator (distance, fuel use, fuel price, passengers, CO2 saved), safety tips for riders and drivers, and a 'coming soon' section. Must not imitate or reference BlaBlaCar's branding.

## Look
Cheerful and social: sunny coral and teal on white, chunky rounded headings, playful road/route line illustrations in SVG.
